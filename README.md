# Sistema de Gestão da Vigilância Sanitária

Projeto desenvolvido na disciplina de Linguagens e Tecnologias para Desenvolvimento Web, do curso de Sistemas de Informação da UniCatólica.

## Integrantes

- José Ivan Luz Ramos
- Pedro Rhuan de Oliveira Sales

## Objetivo

Desenvolver um sistema web para cadastro e gerenciamento de estabelecimentos sujeitos à Vigilância Sanitária.

## Funcionalidades previstas

- Autenticação de usuários;
- Cadastro de estabelecimentos;
- Listagem de estabelecimentos;
- Edição de estabelecimentos;
- Exclusão de estabelecimentos;
- Cadastro de endereço do estabelecimento.

## Tecnologias

O projeto será desenvolvido utilizando a stack MERN:

- MongoDB
- Express
- React
- Node.js

## Estrutura do projeto

- `backend/` - API, regras de negócio e acesso ao banco de dados.
- `frontend/` - interface web utilizada pelo usuário.
